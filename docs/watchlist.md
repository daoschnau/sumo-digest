# Борцы, за которыми стоит следить

Заметки для владельца дайджеста, **не инструкция модели**. В промпт этот файл
не подаётся и подаваться не должен: спецификация в разделе 1 прямо запрещает
приоритетных борцов — «ограничения канала (табу на отдельных борцов,
приоритетные борцы, локальные мемы) НЕ применяются, освещать всех».
Список нужен для приёмки: чтобы человек, читая выпуск, понимал, кто есть кто,
и замечал, если про кого-то из них написано мимо.

Транслитерация имён отсюда закрепляется обычным порядком — таблица
в спецификации, пересборка руководства, правило в `config/translit_rules.yml`.
