# Сумо-дайджест

Автоматический обзор новостей профессионального сумо на русском языке. Сбор статей
из закрытого списка японских и англоязычных изданий делает Python, текст выпуска
пишет модель, публикация — статический сайт.

**Состояние: кода ещё нет.** В репозитории лежат техзадание, дорожная карта, конфиги,
схема данных и промпты. Реализация ведётся по этапам из `ROADMAP.md`, начиная с E0.

## Что где

| Файл | Назначение |
| --- | --- |
| `TZ.md` | Техническое задание: архитектура, модули, валидация, деградация |
| `ROADMAP.md` | Этапы E0–E7 с приёмочными критериями |
| `CLAUDE.md` | Правила и инварианты для работы в Claude Code |
| `docs/sumo-digest-agent-spec.md` | Исходная спецификация Notion-агента — первоисточник правил |
| `config/sources.yml` | Закрытый список источников |
| `config/translit_rules.yml` | Правила детерминированной проверки транслитерации |
| `schema/digest.schema.json` | Контракт выходного JSON |
| `prompts/` | Системные промпты для шагов отбора и написания |

## Настройка перед первым запуском

1. В `config/sources.yml` заменить `USER` в `user_agent` на реальный адрес репозитория.
2. Settings → Secrets and variables → Actions → добавить `ANTHROPIC_API_KEY`.
3. Settings → Pages → Source: GitHub Actions (когда дойдёте до E4).
4. Проверить `data/state.json`: `last_issue_date` задаёт начало периода первого выпуска.
5. Расписание в `.github/workflows/digest.yml` закомментировано намеренно —
   раскомментировать на этапе E5, когда пайплайн заработает.
