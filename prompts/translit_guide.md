# Руководство по транслитерации

*Дата обновления оригинала: 31 августа 2026 г.*

## 1. Общие принципы

**Приоритет использования**
- При наличии устоявшегося варианта написания использовать именно его, даже если он отличается от стандартных правил.
- При первом упоминании нового имени или термина согласовывать написание с владельцем.

**Специфические правила**
- し (shi) → «ш» (не «си»)
- ち (chi) → «ч» (не «ти»/«чи»)
- じ (ji) → «дж» (не «дзи»)
- долгая «о:» → «о» (без удвоения)
- «фу:» в 富士 (fuji) → «фуджи»

**Чтение имён**
- Приоритет он-чтения: 豊 = «ho» (не «toyo»), 昇 = «sho» (не «nobori»), 龍 = «ryu» (не «tatsu»).
- Двухступенчатая транслитерация: 豊昇龍 → Hoshoryu → Хошорю.
- sho → «шо» (не «сё»), jo → «джо» (не «дзё»), ryu → «рю» (не «рью»), kyo → «кё» (не «киё»).
- Конфликт правила и устоявшейся формы → побеждает устоявшаяся форма.
- Новое имя: найти официальную романизацию (сайт Японской ассоциации сумо) → транслитерировать с английского → пометить как требующее подтверждения.

## 3. Термины

**Турниры и мероприятия**
- Региональный тур → тур/дзюнгё («Хару Дзюнгё 2025»)
- «Весенний басё» → «Хару Басё»; аналогично для прочих сезонных турниров — японские названия (Аки Басё, Нагоя Басё и т. д.)

**Звания и ранги**
- «одзэки» → **озеки**
- «хэя» → **бейя**; название бейи всегда «\<Название>-бея» (Тацунами-бея, Исеноуми-бея, Такасаго-бея, Анджигава-бея), никогда «комната X» или «конюшня X»
- «сэкивакэ» → **секиваке**
- «маэгасира»/«маэгашира» → **маегашира**
- **комусуби** (не «комусубэ»)
- 関取 → **секитори** (формы «сэкидзо» не существует)
- 番付 → **бандзуке** (не «банзукэ», «банзуке», «бандзукэ»)
- Глава/хозяин бейи и функционеры Ассоциации → **ояката**

**Дивизионы**
- 幕内 makuuchi → макуути, первый/высший дивизион, топы
- 十両 jūryō → дзюрё, второй дивизион
- оба вместе → секитори, два высших дивизиона
- 幕下 makushita → макушита, третий дивизион
- 三段目 sandanme → санданмэ, четвёртый дивизион
- 序二段 jonidan → дзёнидан, пятый дивизион
- 序ノ口 jonokuchi → дзёнокучи, шестой/низший дивизион

**Техники и приёмы**
- 張り手 harite → харитэ (не «хариматэ») — удар открытой ладонью
- 左四つ hidari-yotsu → хидари-ётсу
- «ётсу» — техника захвата за пояс (маваши), а не «четверной захват»
- 黒星 kuroboshi → куробоши — поражение (не путать с 金星 кинбоши)
- 四股 shiko → шико; 摑り足 suriashi → суриаши

## 4. Контрольный список ошибок (проверять каждый выпуск)

1. Слог **shi** всегда «ши», а не «си»: макушита, синдеши-кенса, Арашио, Аонишики, суриаши.
2. Слог **ji** всегда «джи», а не «дзи»: Танджи, Фуджинокава.
3. В заимствованиях по умолчанию «е», а не «э»: секиваке, секитори, бандзуке, кенса.
4. Не выдумывать термины: нет в руководстве → официальная романизация + пометка «требует проверки».
5. Без знаков ударения и латиницы внутри русских имён.
6. «Любительское сумо», а не «аматорское».
7. Единообразие: одно имя/термин — одно написание в пределах выпуска.
8. Каждое имя рикиши при первом упоминании — с японским написанием в скобках.
9. Бейя всегда «\<Название>-бея».

## 5. Форматирование

- Японские термины — кириллицей; при первом упоминании пояснение в квадратных скобках.
- Формат заголовка новости: `[дата] — [место] — [подзаголовок]`, далее абзац текста.
- Японское написание имени — только из прочитанного источника или руководства.
